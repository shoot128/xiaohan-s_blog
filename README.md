# 📖 静谧书斋 · 个人博客

一个**纯前端、零服务器**的极简个人博客系统，数据完全由你掌控。

> 本站由 [DeepSeek](https://deepseek.com) 辅助生成，代码可能稚嫩，若有 Bug 请多多谅解。  
> 欢迎提交 [Issues](https://github.com/你的用户名/你的仓库/issues) 帮助改进！

---

## ✨ 特点

- 🌐 **公开访问**：访客无需登录即可阅读你发布的公开文章  
- 🔐 **内容加密**：公开文章以加密形式存储在仓库中，保护原始数据  
- 💻 **离线管理**：所有文章和个人信息都保存在浏览器本地，无需服务器  
- 🎨 **双主题**：支持浅色/深色模式，一键切换  
- 📱 **响应式设计**：适配手机、平板和桌面  
- ⚡ **纯静态**：可直接部署到 GitHub Pages，无需数据库或后端

## 🚀 快速开始

### 1. 在线使用（推荐）
1. 访问你的部署网址（例如 `https://你的用户名.github.io/仓库名`）
2. 进入 **管理后台**（`admin.html`），初始密码为 `bilibili`
3. 撰写文章、设置个人信息
4. 点击 **导出加密公开包** 和 **导出个人信息加密包**，下载 `posts.enc` 与 `profile.enc`
5. 将这两个文件上传到仓库的 `data/` 目录下（首次需创建该目录）
6. 返回首页，公开文章标签页即显示最新内容

### 2. 本地运行
直接克隆本仓库，用浏览器打开 `index.html` 即可体验（部分加密功能需配合 `data/` 目录下的文件）。

---

## ⚠️ 注意事项

- **密码固定**：管理后台默认密码为 `bilibili`，如需修改请直接编辑 `admin.html` 中 `FIXED_PASSWORD` 变量的值。
- **数据备份**：请定期使用后台的“导出明文备份”功能，防止浏览器数据丢失。
- **加密密钥**：本项目使用固定公共密码 `MyPublicBlogKey2024!` 进行加解密。若需更改，请同步修改 `index.html`、`admin.html`、`post.html` 中 `PUBLIC_PASS` 的值，并重新导出所有加密包。
- **纯离线本质**：所有云端功能（如同步到 GitHub 仓库）仅为可选扩展，核心逻辑完全离线可用。
